## The build

- What I built: A single-screen "Single Pane of Glass" (SPoG) dashboard mockup for a recruiter working an active requisition. It aggregates data that today lives in three separate systems — LinkedIn Recruiter (sourcing), HiredScore (candidate grading), and Accurate (background check status) — into one candidate pipeline view, with a horizontal stage-tracker replacing per-system navigation. Includes an explicit "old way" caption naming which logins/systems the screen replaces, and a visible "open before build" list surfacing unresolved risks (security/PII review, vendor API confirmation, unvalidated recruiter feedback) rather than hiding them.
- Tool used: Built as an HTML/CSS artifact in Claude, not one of the five listed tools (Lovable / v0 / Cursor / Bolt / Replit) — flagging this explicitly rather than picking one that doesn't match what actually happened. If the lab requires one of those five specifically, this build doesn't satisfy that constraint as-is and would need to be rebuilt or ported.
- Shareable link: None — this lives in a Claude conversation as a downloadable HTML file. Also on Lovable - https://reqflow-talent-hub.lovable.app
